Quantum-Resistant Key Management: Enhancing Cryptographic Security Against Post-Quantum Threats in Modern Network Architectures

Prepared by Waleed H. Al-Fakiat

01 / SHOR'S ALGORITHM

Shor's Algorithm Shatters Classical Public Keys

Quantum computers solve integer factorization and discrete logarithms in polynomial time, compromising asymmetric key exchange.

02 / GROVER'S ALGORITHM

Grover's Search Halves Symmetric Key Strength

Quadratic quantum search reduces an n-bit cipher to n/2-bit security, weakening lightweight IoT ciphers.

03 / TEMPORAL RISK

Harvest-Now, Decrypt-Later Creates Immediate Risk

Adversaries harvest encrypted network traffic today to decrypt sensitive data once fault-tolerant quantum computers arrive.

04 / PROBLEM STATEMENT

Heavy Post-Quantum Keys Overwhelm Constrained IoT Devices

Standardized PQC payloads exceed the strict memory, energy, and processing budgets of low-power wireless sensor nodes.

05 / LITERATURE SYNTHESIS

NIST ML-KEM Sets Standards, Yet Edge Integration Lags

Existing literature lacks a unified hybrid framework merging NIST ML-KEM with energy-efficient Substitution-Permutation Network ciphers.

06 / PROPOSED SOLUTION

Hybrid Architecture Bridges ML-KEM and Lightweight SPN

Our hybrid framework pairs quantum-resistant lattice key encapsulation with a fast, low-power SPN block cipher.

07 / CORE INNOVATION

Optimized Key Schedule Minimizes Edge CPU & RAM

A custom lightweight key schedule derives quantum-hardened round keys on the fly without exhausting microcontroller memory.

08 / VALIDATION & METRICS

Proven Grover Resistance With Superior Edge Performance

Formal cryptanalysis verifies quantum key-recovery resistance while simulations validate high throughput and minimal battery drain.

09 / CONCLUSION & VISION

Forward-Secure Key Management for Post-Quantum IoT Networks

Delivering lasting quantum resilience without sacrificing network throughput or battery life.
